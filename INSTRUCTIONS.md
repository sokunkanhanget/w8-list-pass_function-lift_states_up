# W8 Practice – Lists, Pass Functions, Lift State Up

The exercises are in the handout: **`W9 - PRACTICE-  Lists,  Pass Functions.docx`** (in this folder; the handout title inside says W8).

- **Homework: EX 1 to EX 4** (BONUS if you want).
- **No AI tools.** You will be asked to explain your own code.

## How to run

1. Open **this folder** in VS Code (File > Open Folder).
2. Terminal: `flutter pub get`
3. Terminal: `flutter run -d chrome`
4. After each change, press `r` in the terminal (hot reload).

One project, one folder per exercise:

| Exercise | Folder |
| --- | --- |
| EX 1 – Loop when creating widgets | `lib/ex1/` |
| EX 2 – Switch screen using a state | `lib/ex2/` |
| EX 3 – Bind with data | `lib/ex3/` |
| EX 4 – Manage a list of jokes | `lib/ex4/` |

To switch exercise: in `lib/main.dart`, change `const exercise = 1;` to 2, 3 or 4, then press **`R`** (capital R = hot restart).
